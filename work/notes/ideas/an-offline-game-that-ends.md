# An offline game that ends, and hands out gems over time

Stratagems' offline world never ends, and gems come only from the distributor (the HUD's "Get test gems", and the played seats restake from it when their reserve runs dry, P5 of step O in `work/plans/join-template-commit-reveal.md`). The user, deciding P5 on 2026-10-26: kept simple for now; an offline game should probably END after a number of cycles (with a winner read off the leaderboard), and may hand out gems over time instead of on demand. Both are a game's rules rather than the world's mechanism, so they belong in stratagems; ending is the one that changes the contracts (or a client-side rule over a manual cycle count).
